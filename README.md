
Temperature Converter

Overview

The Temperature Converter is a simple web application that allows users to convert temperatures between Celsius (°C), Fahrenheit (°F), and Kelvin (K). It is built using HTML, CSS, and JavaScript.

Features

Convert temperature between Celsius, Fahrenheit, and Kelvin.

User-friendly interface with a clean design.

Instant conversion with a single button click.

Technologies Used

HTML: Structure of the web page.

CSS: Styling and layout.

JavaScript: Functionality for temperature conversion.
